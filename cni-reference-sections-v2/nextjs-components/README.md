# CNI — Ready-to-use Next.js 14 app

Standalone Next.js demo of both redesigned sections. Run `npm install` and then `npm run dev` in this folder, or copy `components/DivisionShowcase.tsx`, `components/ImmersiveGrid.tsx`, and `components/content.ts` into your existing Next.js 14 project and copy the styles in `app/globals.css` (make sure to move `public/assets/architectural-placeholder.svg`). Insert `<DivisionShowcase />` and `<ImmersiveGrid />` immediately after your existing hero; do not replace your real site's root layout.

Uses the copy from your uploaded CNI website material; images first try the official CNI URLs, then illustrative Unsplash fallbacks. Replace fallback photos and text wordmark with your approved brand assets before publishing.
